# 页面底部水印设计

## 目标

在指定的 C 端页面底部增加统一的品牌水印，文案为“今华有 | 技术支持”。水印应位于页面内容与系统 TabBar 之间，不遮挡内容、不拦截交互，并保持不同页面的视觉和间距一致。

## 页面范围

接入以下顶层页面：

- `pages/category/category`
- `pages/cart/cart`
- `pages/mine/mine`
- `pages/materials/materials`
- `pages/settings/settings`

明确不接入：首页、商品详情、登录页、推广页、支付页，以及设置下的收货地址和提现银行卡页面。

## 组件设计

新增 `mini_shop/components/PageWatermark.vue`，组件只负责展示固定文案，不包含导航、请求、点击事件或业务状态。

默认视觉规则：

- 透明背景，与页面底色融合；
- 文案水平居中；
- 使用浅灰色、小字号和低对比度，接近参考图的底部技术支持水印；
- 组件本身不使用固定定位，不覆盖原有内容；
- 保留足够的上下留白，避免贴近列表、操作栏或系统 TabBar。

## 页面集成

- 购物车、我的、商品素材、设置：将组件放入各自滚动内容的末尾，作为内容流的一部分。
- 分类页：现有页面由左右两个独立 `scroll-view` 组成，组件放在双栏主体下方的公共底部区域；同步为左右滚动区预留水印高度，避免底部商品或分类项被遮挡。
- 首页保持原有结构不变，避免影响轮播图、福利与资讯及其自适应逻辑。

## 交互与兼容

- 水印不可点击，不改变页面事件冒泡和滚动行为。
- 不新增接口、不读取后端配置、不改变登录、购物车、订单、钱包和支付逻辑。
- 不改变原有 TabBar 配置和页面路由。
- 页面在加载中、空数据和长列表状态都应保持结构稳定；水印不参与业务数据判断。

## 验证标准

1. 5 个目标页面均显示完整文案，文字居中且不被 TabBar 遮挡。
2. 首页、商品详情、推广页、支付页、登录页和设置子页均不显示水印。
3. 分类页左右区域仍可独立滚动，底部水印不覆盖商品卡片或分类项。
4. 购物车底部结算栏、我的页面弹窗、商品素材海报弹窗和设置页表单交互不受影响。
5. 小程序端模板、样式和 TypeScript 构建检查通过。
