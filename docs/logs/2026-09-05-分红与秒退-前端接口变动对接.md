# 今华有肽 · 分红模块 + 秒退 前端接口变动对接记录

> 日期：2026-09-05
> 依据：`docs/plan/wxstore分红-前端接口变动说明.md`（v10 大池子方案）

## 一、背景

后端按「v10 大池子」方案调整了分红模块：废弃了 2 个手动接口，改为定时任务自动结算/发放；同时澄清了秒退/退款接口（订单详情已返回 `payTime`）。前端按文档调整。

## 二、B 端：移除废弃的手动结算/发放按钮

按文档，`POST /api/admin/profit/settle`（手动结算）、`POST /api/admin/profit/pool/{poolId}/confirm`（手动发放）已废弃（返回 code 1000），前端移除/隐藏对应按钮。

### 改动（`admin/src/views/profit/index.vue`）
- **移除「手动结算」按钮**（`/settle`）：
  - 「7 天红包」tab 工具栏「结算周期」按钮 → 移除，改为「刷新」。
  - 「红包测试」tab 步骤3「结算每日红包」按钮 → 移除，改为只读提示（系统 00:00 自动结算）。
- **移除「手动发放」按钮**（`/pool/{poolId}/confirm`）：
  - 「7 天红包」tab 操作列「确认并发放」按钮 → 移除（保留「明细」「调整」）。
  - 「红包测试」tab 步骤4「确认发放」按钮 → 移除，改为只读提示（系统 00:00 自动发放）。
- 清理不再引用的函数/状态：`settlePool`、`settleTestPool`、`confirmPool`、`confirmTestPool`、`settleForm`、`testSettleForm`。
- **保留**：`inject`（手动注入）、`adjust`（调整）、`emergency-pool`（应急池）、`slots`/`limits`/`resetLimit` 等保留接口，未改动。

> 说明：`store.settle`/`store.confirm`（api/stores/profit.ts）方法保留未删，仅页面不再调用，无副作用。

## 三、C 端：秒退窗口 + 售后切换

按文档第七节，订单详情已返回 `payTime`，前端据此判断秒退窗口。**今华有肽秒退窗口定为「支付后 30 分钟」**（沿用原口径）。

### 改动
- `mini_shop/api/order.ts`：`OrderSummary` 补充 `payTime?: string`（支付完成时间，订单详情已返回）。
- `mini_shop/subpkg-order/orders/detail.vue`：
  - 新增常量 `SEC_REFUND_WINDOW_MS = 30 * 60 * 1000`。
  - 新增 `canSecRefund` computed：`status===1` 且 `payTime` 距今 ≤ 30 分钟 → 可秒退。
  - 按钮逻辑（`status===1`）：
    - `canSecRefund` → 显示「**立即退款**」→ `refundOrderFast`（秒退，`POST /api/order/refund/fast/{id}`，原路退回，30分钟内）。
    - 否则 → 显示「**申请售后**」→ `refundOrder`（普通退款，`POST /api/order/refund/{id}`，售后审核）。
  - `action` 函数恢复 `refundFast` 分支（`refundOrderFast`）。
