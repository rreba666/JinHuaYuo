# 2026-09-07 后台新增「分红随机浮动幅度」配置

## 背景
后端《wxstore分红-前端接口变动说明 .md》新增配置项 `dividend_random_float`（默认 10）：
- 含义：**池2 起，每人分到的金额 = 均分基准 ± 浮动幅度（元）**，在后端 `[基准−浮动, 基准+浮动]` 内随机。
- 后端已支持读取 + 默认值；需在后台系统设置页提供**可视化配置入口**（key=`dividend_random_float`）。

## 改动（`project-v1.4.0-prod`，admin）
- `src/types/setting.ts`：新增 `RandomFloatConfig { floatAmount, remark }`。
- `src/api/setting.ts`：新增 `getRandomFloatConfig()`（`GET /api/admin/setting/dividend-random-float`，未配置默认 10）与 `saveRandomFloatConfig()`（`POST /api/admin/setting/dividend-random-float`，key=`dividend_random_float`，0~100 校验）。
- `src/stores/setting.ts`：新增 `randomFloat` state、`loadRandomFloat`/`saveRandomFloat`、`randomFloatLoading`/`randomFloatSaving` 并纳入 return。
- `src/views/settings/index.vue`：在"每日随机红包"卡片后新增「分红随机浮动幅度」配置卡（浮动幅度 + 备注 + 保存），并纳入刷新。

> 说明：现有"每日随机红包"（`dividend-random-min/max`，默认 10~50）是**每日红包金额区间**，和新配置**不同**；新配置是**池2起单人金额的随机浮动幅度**。

## 待后端确认
接口路径按现有 `dividend-random-min/max` 模式推断为 `GET/POST /api/admin/setting/dividend-random-float`。若后端实际路径不同，仅需改 `api/setting.ts` 中这两处路径即可。

`pnpm exec vue-tsc --noEmit` 无错误，`pnpm build` 成功。打包 `admin/admin-dist-分红浮动配置-v1.4.0-prod.zip`。
