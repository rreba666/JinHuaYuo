# 2026-09-07 自提订单优化：取货人显示

## 背景
小程序自提订单需优化：下单前填写取货人姓名+电话，并在订单详情相关页面显示。

## 核对结果
- **下单前填写姓名/电话**：已在 `subpkg-order/payment/payment.vue` 实现——选择「门店自提」（`pickupType===1`）时显示"联系方式"区，必填 `contactName`（姓名*）与 `contactPhone`（手机号*），提交时写入 `receiverName`/`receiverPhone`，并随 `pickupShopId` 一并提交。**此部分无需改动**。
- **订单详情**：此前自提订单只显示门店信息（自提时间/店主电话/自提地址/地图），**未显示取货人姓名电话**。

## 改动（`mini_shop/subpkg-order/orders/detail.vue`）
- 在自提信息卡片（`pickupType===1`）内、首行新增「取货人」展示：`{{ order.receiverName }} {{ order.receiverPhone }}`。
- 用 `v-if="order?.receiverName || order?.receiverPhone"` 兼容空值（历史/未填时隐藏该行），取值复用订单详情的 `receiverName`/`receiverPhone`（与物流订单"收货人"同字段，详情接口已返回）。

## 说明
- 配送信息（物流订单）卡片原有的"收货人"展示不受影响。
- 下单填写地址/联系人逻辑无需改动，本次仅补齐订单详情的取货人显示。
- 需 HBuilderX 重新编译并在真机/微信预览验证自提订单详情出现"取货人 姓名+电话"。
