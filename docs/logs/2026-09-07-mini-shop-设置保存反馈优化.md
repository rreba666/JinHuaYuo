# 2026-09-07 收货地址/银行卡 保存反馈优化（自定义 toast）

## 背景
用户反馈设置里"收货地址、银行卡"填写保存后反馈感不强。原生 `uni.showToast` 样式固定（只能选图标类型），无法美化，改用**自定义成功 toast 组件**。

## 改动
- 新增 `mini_shop/components/SuccessToast.vue`：居中深色圆角卡片 + 绿色渐变对勾图标 + 白字 + 淡入淡出动画，约 1.5s 自动消失（`show(text)` 方法），替代原生 `uni.showToast(icon:'success')`。
- `pages/settings/address/address.vue`：保存（地址已添加/已更新）、删除（地址已删除）、设为默认（已设为默认），改用 `successToastRef.show(...)`。
- `pages/settings/bank-card/bank-card.vue`：保存（银行卡已绑定/已更新）、解绑（已解绑），改用 `successToastRef.show(...)`。
- 删除临时工具 `utils/feedback.ts`（被组件取代，无引用）。

## 说明
- 失败反馈仍用原生 `icon:'none'` toast 展示后端错误信息。
- 需 HBuilderX 重新编译，真机验证保存/删除/设默认后弹出居中绿色对勾 toast。
