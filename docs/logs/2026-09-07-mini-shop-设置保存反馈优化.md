# 2026-09-07 收货地址/银行卡 保存反馈优化

## 背景
用户反馈设置里"收货地址、银行卡"填写保存后反馈感不强（原生 `uni.showToast` 灰底、1.5s、无震动，感知弱）。

## 改动
- 新增 `mini_shop/utils/feedback.ts`：统一成功反馈 `successToast(title)` —— 图标 success toast（时长 1800ms）+ `uni.vibrateShort()` 轻震动，提升确认感。
- `pages/settings/address/address.vue`：保存成功（地址已添加/已更新）、删除（已删除）、设为默认（已设为默认）改用 `successToast`。
- `pages/settings/bank-card/bank-card.vue`：保存成功（银行卡已绑定/已更新）、解绑（已解绑）改用 `successToast`。

## 说明
- 成功反馈统一为"图标 toast + 震动"，失败仍为 `icon:'none'` toast 保留后端错误信息。
- 需 HBuilderX 重新编译，真机验证保存/删除/设默认后有震动 + 更明显成功的图标 toast。
