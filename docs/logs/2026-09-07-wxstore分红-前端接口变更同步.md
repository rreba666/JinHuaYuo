# 2026-09-07 wxstore分红-前端接口变更同步

后端更新了 `docs/plan/wxstore分红-前端接口文档.md`，以下为前端同步跟进内容。

## 一、C 端小程序（`mini_shop`）

### 1. 省市区三级联动（新增）
- 新增 `api/region.ts`：`Region` 接口 + `getRegionList(parentCode?)` / `getProvinces()` / `getCities()` / `getDistricts()`，走 `GET /api/region/list`。
  - 不传 `parentCode` 返回省级；传省 code 返回市；传市 code 返回区县。
  - 返回字段：`{code, name, parentCode, level}`（level：1省 / 2市 / 3区县）。
- `pages/settings/address/address.vue`：在"手机号"下方新增 `<picker mode="multiSelector">` 三级联动（绑定 `:range` / `:value` / `@columnchange` / `@change`），联动刷新下级列并在确认后回填 `form.province/city/district`；保留省/市/区三个手输 `input` 兜底（后端允许规范名称手输）。`openCreate`/`openEdit` 时调用 `loadProvinces()` 加载省列表。

### 2. 银行列表（新增）
- 新增 `api/bank.ts`：`Bank` 接口 + `getBankList()`，走 `GET /api/bank/list`，返回 20 家 `{bankCode, bankName, sort}`。
- `pages/settings/bank-card/bank-card.vue`：在"银行名称"输入框上方新增 `<picker mode="selector">` 银行下拉（绑定 `:range` / `:value` / `@change`），选中后回填 `form.bankName`；`bankName` 仍可手输兜底（下拉找不到时）。`openCreate`/`openEdit` 时调用 `loadBanks()`。

### 3. 购物车步进器
- 后端 `updateQuantity` 参数顺序 bug 已由后端修复（原 `WHERE id=userId AND user_id=cartId` → 现 `WHERE id=cartId AND user_id=userId`）。
- 前端调用 `PUT /api/cart/{cartId}/quantity/{quantity}` 不变，契约一致，本次未改。

## 二、B 端后台（`project-v1.4.0-prod`，admin）

### 每日红包"已结算"（新增）
- `src/types/profit.ts`：`SevenDayBonusDetail` 新增 `settlementVersion?: string`（结算版本，如 `V2`）。
- `src/api/profit.ts`：`normalizeDetail` 保留 `settlementVersion`；新增 `getSettledDailyDetails()` → `GET /api/admin/profit/daily/settled`（`pool_id` 非空的多日明细，含 `settlementVersion`、`dailyUserCount` 自动统计）。
- `src/stores/profit.ts`：新增 `settledDaily` state；`fetchAll` 并行加载 `settledDaily`；`return` 增加 `settledDaily`。
- `src/views/profit/index.vue`：在"未结算每日红包"卡片后新增"已结算每日红包"卡片，表列：明细 ID / 父红包 ID / 日期 / 每日金额 / 参与人数 / 版本。
